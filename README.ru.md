# Research Orchestrator

[English](README.md) · [Русский](README.ru.md) · [Español](README.es.md)

**Хватит собирать вкладки. Начните связывать доказательства.**

Навык для ИИ-агента: от точечного поиска факта до исследования веба, GitHub, документов, научных публикаций и подключённых внутренних источников.

## Что делает

Быстрые проверки, глубокие сравнения, изучение кода и обсуждений GitHub, исследования по нескольким типам источников.

## Как работает

Разбивает вопрос на направления, при наличии возможностей делегирует их и объединяет выводы со ссылками, противоречиями и пробелами.

## Требования

Для делегируемых режимов нужна среда с поддержкой субагентов и соответствующие инструменты поиска.

## Установка

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/jezannn16/research-orchestrator.git ~/.agents/skills/research-orchestrator
```
