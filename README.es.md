# Research Orchestrator

[English](README.md) · [Русский](README.ru.md) · [Español](README.es.md)

**Deja de acumular pestañas. Conecta la evidencia.**

Una habilidad para agentes que convierte una pregunta en una investigación con fuentes web, GitHub, documentos, publicaciones académicas y fuentes internas conectadas.

## Qué hace

Consultas rápidas, comparaciones web, análisis de código e incidencias de GitHub e investigaciones con varios tipos de fuentes.

## Cómo funciona

Divide las preguntas complejas en perspectivas, delega cuando es posible y reúne resultados con citas, contradicciones y lagunas.

## Requisitos

Los modos delegados requieren un entorno compatible con subagentes y herramientas de búsqueda.

## Instalación

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/jezannn16/research-orchestrator.git ~/.agents/skills/research-orchestrator
```

> Compara las principales opciones de código abierto para [problema], cita las fuentes y señala las lagunas.
