# Research Orchestrator

Choose the research mode that fits the request. For combined questions, use one report and load each relevant mode guide.

| Request | Mode guide |
|---|---|
| One current fact, price, role, date, or focused lookup | Read references/quick-web-search.md |
| Comparison, survey, landscape, or synthesis across five or more web sources | Read references/deep-web-research.md |
| Research combining web with local files, academic papers, internal tools, or official docs | Read references/multi-source-research.md |
| Open-source project search, code examples, issues, pull requests, releases, licenses, or maintainer activity | Read references/github-research.md |

## Shared workflow

1. Identify the question, available sources, and the evidence needed to answer it.
2. Read the relevant mode guide. For combined research, use the multi-source guide as the report framework and add other relevant modes.
3. Before delegating, read the helper instructions for each source angle from references/source-agents or references/github-agents.
4. Delegate only distinct research angles that can be checked independently. Follow the selected mode's limits on parallel work and follow-ups.
5. Synthesize findings in original prose. Cite specific claims, distinguish evidence from inference, surface source conflicts, and report meaningful gaps. Never show raw worker JSON.
6. Save a report only when the user asks for a file.

For a web-only question, use the focused or deep web mode. When GitHub is one of several source types, use the multi-source mode and include the GitHub guide for that angle.

## Output language

Write in the language requested by the user, or match the language of the request.
